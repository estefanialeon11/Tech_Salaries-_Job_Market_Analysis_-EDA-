# Tech_Salaries-_Job_Market_Analysis_-EDA-
Análisis exploratorio de datos en Python sobre una muestra de más de 9,000 registros salariales del sector tecnológico. El proyecto evalúa la distribución de compensaciones según nivel de experiencia, modalidad de trabajo y especialización del rol.

## 🛠️ Tecnologías y Librerías
* **Python**
* **Pandas** (Procesamiento y limpieza de datos)
* **Seaborn & Matplotlib** (Visualización estática avanzada)

## 💡 Hallazgos Clave (Key Insights)
* **Escalabilidad por Experiencia:** La mediana salarial inicia en ~$75,000 para perfiles *Entry-level* y alcanza los ~$185,000 en roles *Executive*, duplicando ampliamente la base salarial inicial.
* **Modalidad de Trabajo:** Los esquemas *Presencial* ($145,000) y *Remoto* ($137,141) registran medianas comparables, mientras que la modalidad *Híbrida* ($74,000) presenta la menor compensación promedio dentro del dataset.
* **Roles Top Pagados:** Las posiciones ejecutivas de datos (*Head of Data* con $204,500 y *Director of Data Science* con $202,016) encabezan el mercado, seguidas de cerca por ingenierías especializadas en Machine Learning e Inteligencia Artificial.
